# WCAG 2.2: critérios para cognição

A WCAG não tem uma seção "cognitiva". Os critérios relevantes estão espalhados pelos quatro princípios da norma (perceptível, operável, compreensível e robusto). Aqui eles estão reunidos por nível e ligados aos [perfis por dificuldade](../perfis/index.md).

!!! info "Novos na WCAG 2.2"
    A versão 2.2 (2023) trouxe três critérios pensados diretamente para cognição: **3.2.6 Ajuda consistente**, **3.3.7 Entrada redundante** e **3.3.8 Autenticação acessível**. Eles estão marcados com ★.

## Nível A — o mínimo

| Critério | O que pede, em uma frase | Perfis |
|---|---|---|
| 1.1.1 Conteúdo não textual | Imagens, ícones e emoji têm alternativa em texto | Comunicação social |
| 1.3.3 Características sensoriais | Instruções não dependem só de forma, posição ou som | Percepção |
| 1.4.1 Uso de cor | Cor nunca é o único jeito de passar a informação | Percepção |
| 1.4.2 Controle de áudio | Dá para parar áudio que toca sozinho | Atenção · Percepção |
| 1.2.2 Legendas (gravadas) | Vídeos têm legenda | Velocidade · Leitura |
| 2.2.1 Tempo ajustável | Limites de tempo podem ser desligados, ajustados ou estendidos | Velocidade · Fadiga |
| 2.2.2 Pausar, parar, ocultar | O que se move por mais de 5 s tem pausa | Atenção · Velocidade |
| 2.3.1 Três flashes ou abaixo do limite | Nada pisca mais de 3 vezes por segundo | Percepção |
| 2.4.2 Página com título | O título diz onde a pessoa está | Planejamento |
| 2.4.3 Ordem do foco | O foco segue uma ordem que faz sentido | Atenção |
| 3.2.1 Em foco | Focar um elemento não muda de página nem abre nada | Atenção · Planejamento |
| 3.2.2 Em entrada | Preencher um campo não muda de contexto sozinho | Velocidade · Planejamento |
| 3.2.6 Ajuda consistente ★ | Ajuda fica no mesmo lugar em todas as páginas | Memória · Planejamento · Comunicação social |
| 3.3.1 Identificação do erro | O erro é descrito em texto | Planejamento |
| 3.3.2 Rótulos ou instruções | Campos têm rótulo e instrução visíveis | Memória · Leitura · Números |
| 3.3.7 Entrada redundante ★ | Não pedir de novo o que já foi informado | Memória · Fadiga |

## Nível AA — o que costuma ser exigido

| Critério | O que pede, em uma frase | Perfis |
|---|---|---|
| 1.3.5 Identificar o propósito da entrada | Campos de dados pessoais usam `autocomplete` | Memória |
| 1.4.3 Contraste (mínimo) | Texto com contraste de pelo menos 4,5:1 | Percepção |
| 1.4.11 Contraste não textual | Bordas e ícones importantes com contraste de 3:1 | Percepção |
| 1.4.12 Espaçamento de texto | Aumentar espaçamentos não quebra o conteúdo | Leitura · Percepção |
| 2.4.5 Várias formas | Mais de um caminho até o conteúdo (menu, busca, mapa) | Fadiga · Planejamento |
| 2.4.6 Cabeçalhos e rótulos | Títulos e rótulos descrevem o propósito | Leitura · Planejamento |
| 2.4.11 Foco não encoberto (mínimo) | Nada cobre o elemento em foco | Atenção |
| 3.1.2 Idioma de partes | Trechos em outro idioma estão marcados | Leitura |
| 3.2.3 Navegação consistente | Menus no mesmo lugar e na mesma ordem | Memória · Planejamento · Comunicação social |
| 3.2.4 Identificação consistente | Mesma função, mesmo nome | Memória · Planejamento · Comunicação social |
| 3.3.3 Sugestão de erro | O erro diz como corrigir | Planejamento · Números |
| 3.3.4 Prevenção de erros (jurídico, financeiro, dados) | Revisar, confirmar ou desfazer envios importantes | Planejamento · Números · Fadiga |
| 3.3.8 Autenticação acessível (mínimo) ★ | Login sem teste cognitivo (decorar, transcrever, resolver) | Memória |
| 4.1.3 Mensagens de status | Resultados anunciados sem mover o foco | Planejamento |

## Nível AAA — onde está a maior parte da cognição

| Critério | O que pede, em uma frase | Perfis |
|---|---|---|
| 1.4.7 Som de fundo baixo ou ausente | Fala gravada sem som de fundo competindo | Percepção |
| 1.4.8 Apresentação visual | Linhas curtas, sem justificar, espaçamento adequado | Leitura · Percepção |
| 2.2.3 Sem tempo | O tempo não é parte essencial da tarefa | Velocidade |
| 2.2.4 Interrupções | Interrupções podem ser adiadas | Atenção |
| 2.2.5 Nova autenticação | Dados preservados ao entrar de novo | Memória · Velocidade · Fadiga |
| 2.2.6 Tempo esgotado | Avisar quanto tempo de inatividade causa perda de dados | Velocidade · Fadiga |
| 2.3.3 Animação a partir de interações | Animações de interação podem ser desligadas | Atenção |
| 2.4.8 Localização | A pessoa sabe onde está no conjunto | Planejamento |
| 2.4.10 Cabeçalhos de seção | Conteúdo organizado em seções com título | Leitura · Atenção |
| 3.1.3 Palavras incomuns | Jargão e expressões são explicados | Leitura · Comunicação social |
| 3.1.4 Abreviaturas | Siglas são expandidas | Leitura |
| 3.1.5 Nível de leitura | Texto acessível a quem tem ensino fundamental | Leitura |
| 3.2.5 Mudança mediante solicitação | Nada muda de contexto sem a pessoa pedir | Atenção · Planejamento |
| 3.3.5 Ajuda | Ajuda contextual disponível | Planejamento · Comunicação social |
| 3.3.6 Prevenção de erros (todos) | Revisar ou desfazer qualquer envio | Planejamento |
| 3.3.9 Autenticação acessível (aprimorado) | Login sem nem reconhecimento de objetos | Memória |

!!! tip "O que o CLARO recomenda"
    Trate **todos** os critérios AAA desta página como prática do time, mesmo quando o contrato pede só AA. Quase todos custam pouco quando entram no começo do projeto.

Texto oficial de cada critério: [Understanding WCAG 2.2](https://www.w3.org/WAI/WCAG22/Understanding/).
